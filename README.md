# Chase Whittaker

Building personal operating systems for ADHD founders. Small, opinionated apps for managing money, focus, project portfolios, and job search.

I run too many side projects, so I build the dashboards I need to keep them — and myself — in line. Most of these are for my own daily use first; open-source second.

## What I'm shipping

- **[shipyard-os](https://github.com/iamchasewhittaker/shipyard-os)** — Personal OS for tracking 50+ side projects. *What should I build next?*
- **[moving-the-needle](https://github.com/iamchasewhittaker/moving-the-needle)** — Daily action OS for job search and networking. *What's the smallest action I can take today?*
- **[unnamed-ios](https://github.com/iamchasewhittaker/unnamed-ios)** — Native iOS daily focus OS. Four lanes, one-at-a-time, lock at start of day.
- **[clarityos-money](https://github.com/iamchasewhittaker/clarityos-money)** — Behavioral budgeting OS on top of YNAB. *Phase 0 — watch this space.*
